## 🔄 02. Estruturas de controle

Estudo dos mecanismos utilizados para controlar o fluxo de execução dos programas.

### 🔀 Estruturas condicionais

```python
if
elif
else
```

### 🔁 Estruturas de repetição

```python
for
while
```

Essas estruturas permitem que os programas executem diferentes ações de acordo com determinadas condições e repitam operações quando necessário.
